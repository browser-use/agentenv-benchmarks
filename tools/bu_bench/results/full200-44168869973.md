## Reproduction (paired, same 200 tasks)

- 7/8 harnesses reproduce within noise: paired AgentEnv - ours CI includes 0. Mean diff +0.8, mean |diff| 1.6 points.
- 1/8 does not: Codex + OpenCode browse is +4.2 [+1.0, +7.5] higher on AgentEnv (66.7 vs 62.4).
- Ranking: Spearman 0.93 over the 8 arm means. Same #1 (browser-use agent, +8.0 [+4.6, +11.4] vs Codex + BU CLI here,
  +5.7 [+2.1, +9.4] ours), same bottom two (Stagehand, OpenCode browse, swapped), the 5 middle Codex arms reshuffle
  within noise as they tied on our platform. Stagehand stays clearly below Codex + BU CLI (-8.3 [-12.4, -4.0]); OpenCode
  browse is now -3.3 [-6.8, +0.3] (ours -8.0).
- Per task: Pearson 0.52-0.64 per arm, mean |diff| 12.6-16.3 points. Single tasks swing a lot run to run; means hold.

## Columns
- score: mean judge score x100 (continuous) over 200 tasks; CI = 10k bootstrap over tasks, seed 7.
- paired diffs: per task, then 10k bootstrap. "ours" = our eval platform: bake-off r2 (Nov 12-13) for the 7 Codex arms,
  eval a1487b98 + rejudge e089dc24 (Nov 13) for browser-use 1.0.4rc1 (`reference/bakeoff-full.json`).
- model $/task: everything through the run's model endpoint except judge calls (Codex + Stagehand's own calls), over all
  attempts incl. failed ones, / 200; at $1 in / $0.10 cached / $5 out per 1M (the bake-off basis). judge $/task: the
  gpt-5.6-luna calls at the same basis (its own price not verified). cloud $/task: Browser Use browser + proxy cost
  of the task's session. min/task: browser lifetime (AgentEnv) vs agent wall time (ours), so AgentEnv reads slightly high.

## Retries (all exact task ids, same config)
- 30 infra reruns (run 44274664054): 28 Codex turns in run 44232180986 ended with "Rate limit reached for gpt-6.1-terra"
  (sent inside the response stream; the endpoint logged only 1 HTTP 429, so its backoff never saw them), plus 2 turns
  stalled (no output 300 s). Wave 1 had none. All 30 reran clean.
  agent-browser 10, Browser Use MCP 6, Playwright MCP 5, Stagehand 5, OpenCode browse 4.
- 3 judge errors, never scored 0: codex-bu-cli bu2-125 and codex-stagehand bu2-028 (judge returned empty JSON) rejudged
  on the saved evidence (`tools/bu_bench/rejudge.py`, runs 44232354386, 44274664054): 84, 86. codex-opencode-browse bu2-004: a
  screenshot needs 46,718 image patches (judge model limit 30,000), failed again on rejudge, so the task was rerun
  (44290480070), as the bake-off did for its one such case.
- Kept as scored (agent outcomes, as on our platform): 4 Codex turns hit the 60 min timeout (Stagehand bu2-008, bu2-047,
  bu2-178; Browser Use MCP bu2-071). 66 tasks the judge classed infra-error (site/page did not load) stay scored, as in
  the bake-off.

- One run per arm per platform. OpenCode browse's +4.2 is outside its CI; cause not investigated (live sites drift,
  different week; its relay/extension shim is the most complex tool setup).
- Cloud cost on the 7 Codex arms: $0.30/task on AgentEnv vs $0.24 ours (1.26x; per arm 0.87x to 1.6x), not explained.
  browser-use's own run on our platform recorded no cloud cost.
- The in-stream rate-limit failure mode is not retried by the endpoint; rerunning by task id handled it here.
